# Phase 7 — reports/lab_report.md: Final Written Report

## File to create
`reports/lab_report.md`

## Note
This file is AUTO-GENERATED by `report.py` when you run `make run-scenarios`.
Phase 6 (report.py) handles this automatically. You do NOT need to write it manually.

## To generate
```bash
make run-scenarios
```
This will write `reports/lab_report.md` automatically.

## What to verify after generation
Open `reports/lab_report.md` and confirm all 8 sections are present:
1. Team / Student info filled
2. Architecture description
3. State schema table
4. Scenario results table (all 7 rows)
5. Failure analysis (at least 2 failure modes)
6. Persistence evidence
7. Extension work described
8. Improvement plan

## If you want to add extra evidence manually
After `make run-scenarios`, you can append to `reports/lab_report.md`:
- Output from `python scripts/time_travel_demo.py`
- Output from `python scripts/generate_diagram.py`
- Any screenshots or logs showing crash-resume
